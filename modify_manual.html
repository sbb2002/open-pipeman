Patch Mode // 코드 수정 출력 지침

01  기본 절차
  • 코드 수정을 요청받으면 structure.md를 참고하여 수정할 파일을 선택하고 사용자에게 요청하시오.
  • 사용자가 파일을 전달해주면 해당 파일을 모두 읽고 수정 작업을 시작하시오.
  • 새 기능·디자인·코드가 기존 코드와 충돌할 우려가 있는지 검사하시오.
  • 충돌 우려가 있으면 미리 사용자에게 알리고 해결 방법을 제안한 뒤 재확인을 받아 진행하시오.
  • 추가 수정 요구 시에는 최근 수정한 파일을 기준으로 작업하시오.
02  JSON 패치 규칙
  • 모든 수정 사항은 아래 JSON 양식으로만 작성하십시오. (설명 생략, JSON만 출력)
  • 라인 번호 기준: 1-based index 사용. 빈 줄·주석을 포함한 실제 라인 번호를 정확히 파악하십시오.
  • 패치 전 파일 확인 필수: JSON 출력 전에 반드시 현재 파일의 내용과 줄 번호를 직접 확인하십시오. 이전 대화 기억에만 의존하지 마십시오.
  • 무결성 유지: 같은 파일 내 여러 수정 시 (from, to) 범위가 겹치지 않게 하십시오. 겹치는 구간은 하나의 target 객체로 합치십시오.
  • 들여쓰기: replace 내의 코드는 기존 파일의 들여쓰기 규칙을 엄격히 준수하십시오.
  • 교체 범위 산정: replace 줄 수가 from~to 줄 수와 달라도 동작합니다. 단, 교체 후 주변 코드와 문법적으로 올바르게 이어지는지 확인하십시오.
    • to 줄 번호는 반드시 파일을 직접 열어 눈으로 확인하십시오. 추정하거나 계산으로 산출하지 마십시오. to가 짧으면 원본 잔재 코드가 새 코드 뒤에 붙어 문법 오류가 발생합니다.
    • replace 문자열 안에 백틱(`)과 중첩 템플릿 리터럴을 사용하지 마십시오. JSON 직렬화 과정에서 파싱 오류가 발생합니다. DOM API(createElement, setAttribute 등)를 사용하십시오.
  • 삭제 삽입 전체 교체
    • 삭제: replace: ""를 사용하십시오.
    • 삽입: from과 to를 동일한 줄 번호로 지정하십시오. 기존 줄은 보존되며, 해당 줄 번호 앞에 삽입됩니다.
    • 전체 교체: 변경량이 50줄 초과 또는 구조 손상 시 from: 1, to: (전체 줄 수)로 교체하십시오. 줄 번호 오계산 위험이 없어 더 안전합니다.
03  수정 완료 체크
  • 수정된 기능 및 디자인: 모두 반영
  • 수정하지 않은 원본 기능 및 디자인: 유지
  • index.html을 열었을 때 잘 작동해야 함
04  버전 관리 규칙
  • 이번 세션에서 최초로 업로드한 파일은 자동으로 v1으로 간주한다.
  • JSON 출력 시마다 "version" 필드에 현재 버전을 반드시 명시하시오.
  • 패치 적용마다 버전이 +1 증가한다. Claude는 대화 컨텍스트를 기반으로 각 파일의 버전을 추적하시오.
  • 파일을 재업로드하면 해당 파일의 버전을 v1로 리셋하여 다시 계산하시오.
  • 버전이 불확실한 경우 JSON 출력 전에 사용자에게 확인하시오.
  • "version" 필드는 정보 표시 목적이며, patch_applier.py는 이를 로그로만 출력하고 적용을 차단하지 않는다.
05  patch_applier.py 동작 규칙
  • 교체: replace 문자열을 줄 단위로 분리하여 from~to 구간과 정확히 교체합니다. 줄 수가 달라도 올바르게 처리됩니다.
  • 삽입 (from == to): 기존 줄을 덮어쓰지 않고, 해당 줄 앞에 삽입합니다.
  • 삭제 (replace: ""): 해당 구간을 완전히 제거합니다.
  • 에러 시 중단: 아래 경우 해당 파일의 패치를 중단합니다.
    from > to
    시작 줄이 끝 줄보다 큰 경우
    범위 초과
    범위가 파일 총 줄 수를 초과하는 경우
    범위 중복
    같은 파일 내 target 범위끼리 중복되는 경우
06  JSON Format
patch.json 
[
    {
        "file": "경로/파일명.확장자",
        "version": N,
        "target": [
            {
                "from": 시작_라인_번호,
                "to":   끝_라인_번호,
                "replace": "수정/교체될 코드 내용"
            }
        ]
    }
]
