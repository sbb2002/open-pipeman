# 코드 수정 출력 지침 (Patch Mode)
* 코드 수정을 요청받으면 'structure.md'를 참고하여 어떤 파일을 수정할지 선택하여 사용자에게 요청하시오.
* 사용자가 요청한 파일을 전달해주면 해당 파일을 모두 읽고 수정 작업을 시작하시오.
* 수정하여 추가될 새 기능, 디자인, 코드가 수정하지 않는 기존 기능, 디자인, 코드와 충돌할 우려가 있는지 검사하시오. 
* 만약 충돌할 우려가 있다면 미리 사용자에게 알리고 충돌하지 않을 방법을 제안한 후 사용자의 재확인을 받아 수정작업을 진행하시오.
* 모든 수정 사항은 아래 JSON 양식으로만 작성하십시오. (설명 생략, JSON만 출력)
    * **라인 번호 기준:** 1-based index를 사용하며, 빈 줄과 주석을 포함한 실제 파일의 라인 번호를 정확히 파악하십시오.
    * **무결성 유지:** 같은 파일 내 여러 지점 수정 시 (from, to) 범위가 겹치지 않게 하십시오. 겹치는 구간은 하나의 'target' 객체로 합쳐서 작성하십시오.
    * **들여쓰기:** `replace` 내의 코드는 해당 파일의 기존 들여쓰기 규칙을 엄격히 준수하십시오.
    * **특수 작업:** 삭제는 `replace: ""`를 사용하고, 단순 삽입은 삽입될 위치의 라인 번호를 from과 to에 동일하게 지정하십시오. (이 경우 해당 라인 번호 앞에 코드가 추가됩니다.).
* 수정 완료 후 아래와 같이 체크하시오.
    - 수정된 기능 및 디자인: 모두 반영
    - 수정하지 않은 원본 기능 및 디자인: 유지
    - index.html을 열었을 때 잘 작동해야 함.

[JSON Format]
```json
[
    {
        "file": "경로/파일명.확장자",
        "target": [
            {
                "from": 시작_라인_번호,
                "to": 끝_라인_번호,
                "replace": "수정/교체될 코드 내용"
            }
        ]
    }
]
```
