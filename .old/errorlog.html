🚨 시스템 에러 요약 보고서

발생 위치: 백엔드 연동 중인 LangGraph 기반 애플리케이션 (Node: generate)

현재 상태: 인증 실패로 인한 스트리밍 중단

1. 현상 파악 (무슨 일이 일어났는가?)

  • 프론트엔드: POST /cell/run 요청 중 net::ERR_INCOMPLETE_CHUNKED_ENCODING 200 (OK) 에러 발생 후 네트워크 통신 끊김.
  • 백엔드: 응답을 쪼개서 보내는(Streaming) 도중 데이터 처리가 비정상적으로 중단되어 ASGI 애플리케이션 Exception 터짐.

2. 진짜 원인 (Root Cause)

백엔드 내부의 Anthropic(Claude) API 호출 라이브러리가 API 키를 찾지 못해 에러가 발생했습니다.

TypeError: "Could not resolve authentication method. Expected one of api_key, auth_token, or credentials to be set..."

LangGraph가 node_generate 노드에서 Claude 모델을 실행하려는 순간, 필수 인증 정보(API Key)가 누락되어 전체 스트리밍 파이프라인이 붕괴되었습니다.

3. 해결 방법 (Action Item)

  • 방법 A (.env 설정): 프로젝트 루트의 .env 파일에 ANTHROPIC_API_KEY=내_API_키가 올바르게 설정되었는지 확인하고, 코드 상단에서 load_dotenv()로 불러오고 있는지 체크합니다.
  • 방법 B (터미널 주입): 백엔드 서버를 켜기 전 터미널 환경 변수로 키를 직접 등록한 후 서버를 재시작합니다.
    (예: PowerShell의 경우 $env:ANTHROPIC_API_KEY="키_값" 입력 후 uvicorn 실행)
  • 방법 C (코드 명시): backend.py 내에서 Anthropic 객체를 초기화할 때 Anthropic(api_key="키_값") 형태로 하드코딩하여 테스트합니다. (⚠️ 깃허브 업로드 시 주의)
