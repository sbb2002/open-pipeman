# Session 1. 캔버스 셀 드래그 추가 시 커서 금지 버그

| 파일명 | 버전 | 내용 |
|---|---|---|
| css/base.css | v1 | 전역 `user-select: none` 추가 — 텍스트 박스 외 영역에서 드래그 시 텍스트 선택 방지. `input, textarea, [contenteditable]`은 `user-select: text`로 복원 |
| index.html | v2 | `ondragover` / `ondrop` 핸들러를 `#canvas` → `#canvas-wrap`으로 이동 — `edge-canvas` 등 하위 요소 위에서도 드롭 허용, 금지 커서(🚫) 버그 수정 |
| js/canvas.js | v2 | `dragstart` 시 팔레트 아이템 내 커서 offset(`_dragOffsetX/Y`) 저장, `handleDrop`에서 하드코딩 `-90/-40` 제거 후 실제 offset 반영 — pan/zoom 상태와 무관하게 커서 위치에 정확히 셀 생성 |
| js/canvas.js | v3 | `createNode`, `cloneNode`, `mousemove` 드래그, Ctrl+drag clone, `moveGhosts` 전체에서 `Math.max(0, ...)` 좌표 클램핑 제거 — 캔버스를 사방으로 무한 확장, 음수 좌표 허용 |
| js/canvas.js | v4 | 셀 연결 모드 진입 시 `statusValid.className = 'running'` → `classList.remove('error') + classList.add('running')`으로 교체 — `.status-validity-btn` 클래스 유실로 인한 흰색 배경 버그 수정 |
