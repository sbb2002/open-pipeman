## 세션 내 작업완료 후 structure.md 수정 여부 묻기
지금까지 수정한 파일을 기준으로 structure.md의 주석을 재구성해줘. 만약 큰 변경 사항이 없어서 다른 세션에서 이 주석을 읽어도 작업하는데 지장을 주지 않는다고 판단되면 재구성하지 않아도 된다고 알려줘.

## 세션 내 파일 패치내역 요구
이 세션에서 작업한 내역을 요약해. 요약 시 아래 내용을 참고하여 markdown 양식에서 표로 작성하여 파일로 보여줘. 표의 행 방향은 파일명, 버전 순으로 오름차순 정렬해야해.

* 파일명: 디렉토리/파일.확장자
* 버전: 수정되기 전 파일의 버전을 기입
* 내용: 수정한 내역을 간략하게 요약

## 평가용 요약 페이지 제작(일반)
이 세션에서 진행했던 내역을 요약하여 html로 만들어줘. 아래 보상규칙과 금지규칙을 참고하여 작성하도록 해.

[보상규칙]
* 가독성이 좋게 만들면 +10
* 인터렉티브하게 만들면 +20
* 전달하고자 하는 의도가 명확하게 담겼으면 +30

[금지규칙]
* 전달하고자 하는 의도가 애매하게 담기거나 생략되었으면 -50
* 가독성이 떨어지면 -10
* 주제와 일치하는 중요한 문장을 폰트 사이즈 12 미만으로 작성한 경우 -10
